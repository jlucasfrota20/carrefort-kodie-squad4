DOCUMENTAÇÃO DOS PROMPTS UTILIZADOS NO PROJETO CARREFORT

1. Prompt – Identidade Visual do Carrefort

Objetivo: Criar uma identidade visual sustentável, acolhedora e moderna, transmitindo a ideia de economia, sustentabilidade e redução do desperdício de alimentos.

Prompt utilizado:

Crie uma identidade visual para o sistema Carrefort, uma plataforma de supermercado voltada à divulgação de produtos próximos do vencimento, incentivando o consumo consciente e reduzindo o desperdício de alimentos.

Utilize uma identidade visual sustentável e acolhedora, com tons de verde, off-white e amarelo suave. O design deve ser moderno, limpo, intuitivo e profissional.

Utilize Poppins nos títulos e Inter nos textos. Crie uma proposta de logotipo que combine um carrinho de compras com uma folha, representando sustentabilidade e comércio.

Correções realizadas:

- Padronização das cores da interface.
- Utilização do verde floresta (#245C43) como cor principal.
- Definição das fontes Poppins e Inter.
- Manutenção de uma identidade visual consistente em todas as telas.

---

2. Prompt – Tela de Login Administrativo

Objetivo: Criar uma tela de acesso simples e intuitiva para os funcionários responsáveis pelo gerenciamento dos produtos.

Prompt utilizado:

Desenvolva a tela de Login Administrativo do Carrefort, seguindo a identidade visual sustentável e acolhedora do projeto.

A tela deve conter o logotipo, campo de usuário ou e-mail, campo de senha e botão de entrar.

O acesso será restrito aos funcionários da loja, utilizando um único login compartilhado por estabelecimento.

Mantenha o layout simples, organizado, responsivo e fácil de utilizar.

Correções realizadas:

- Restrição do acesso à área administrativa.
- Remoção de funcionalidades desnecessárias.
- Simplificação dos campos de acesso.
- Padronização visual com as demais telas.

---

3. Prompt – Dashboard Administrativo

Objetivo: Criar um painel inicial que permita aos funcionários visualizar rapidamente a situação do estoque e os produtos próximos do vencimento.

Prompt utilizado:

Crie o Dashboard Administrativo do Carrefort, seguindo a identidade visual definida para o projeto.

O painel deve apresentar uma saudação com o texto "Olá, equipe", indicadores resumidos do estoque e uma seção de alertas de validade.

Organize as informações de maneira clara, destacando os produtos próximos do vencimento e facilitando o acompanhamento do estoque.

Inclua uma barra lateral de navegação para acessar Dashboard, Produtos e Estoque e Histórico.

Utilize componentes visuais simples, organizados e responsivos.

Correções realizadas:

- Alteração da saudação para "Olá, equipe".
- Inclusão dos alertas de validade no próprio Dashboard.
- Padronização da barra lateral.
- Simplificação dos indicadores para atender ao MVP.

---

4. Prompt – Produtos e Estoque

Objetivo: Desenvolver uma interface para cadastrar, visualizar e organizar os produtos registrados no sistema.

Prompt utilizado:

Desenvolva a tela Produtos e Estoque do sistema Carrefort.

A interface deve permitir visualizar os produtos cadastrados e apresentar a opção "+ Cadastrar Produto".

O formulário de cadastro deve conter exclusivamente os campos:

- Nome do produto;
- Categoria: Padaria, Frios ou Hortifrúti;
- Quantidade;
- Data de validade.

Apresente os produtos de maneira organizada, facilitando a identificação dos itens e seus respectivos status de validade.

Mantenha o design simples, intuitivo e alinhado à identidade visual do Carrefort.

Correções realizadas:

- Remoção dos campos de preço e descrição.
- Manutenção somente dos quatro campos definidos para o MVP.
- Integração do cadastro dentro da tela Produtos e Estoque.
- Remoção da necessidade de uma tela separada para cadastro.
- Definição das categorias Padaria, Frios e Hortifrúti.

---

5. Prompt – Histórico e Vitrine de Ofertas

Objetivo: Criar interfaces para acompanhar o destino dos produtos e permitir que os clientes visualizem as ofertas disponíveis.

Prompt utilizado:

Crie as telas Histórico e Vitrine de Ofertas do Carrefort, respeitando a identidade visual sustentável e acolhedora do projeto.

Na tela Histórico, permita acompanhar o destino dos produtos, organizando-os nas categorias Vendido, Doado e Descartado.

Na tela Vitrine de Ofertas, desenvolva uma interface pública, sem necessidade de login, para que os clientes possam visualizar produtos próximos do vencimento.

Inclua pesquisa por nome do produto e filtros por categoria.

Utilize um layout intuitivo, organizado, responsivo e adequado para dispositivos móveis.

Correções realizadas:

- Separação entre a área administrativa e a área pública.
- Retirada da exigência de login para acessar a Vitrine.
- Inclusão da pesquisa por nome.
- Inclusão dos filtros por categoria.
- Organização do histórico conforme o destino dos produtos.

---

RESULTADO FINAL

Após a criação e os ajustes dos prompts, foram desenvolvidas cinco telas principais para o MVP Carrefort:

1. Login Administrativo;
2. Dashboard;
3. Produtos e Estoque;
4. Histórico;
5. Vitrine e Ofertas.

Conclusão: Os prompts foram utilizados para orientar a criação das interfaces e estabelecer uma identidade visual consistente. As correções ajudaram a adequar as telas às necessidades do projeto, mantendo o foco nas funcionalidades essenciais do MVP e evitando recursos desnecessários.

Observação: Os textos apresentados são versões organizadas e reconstruídas dos prompts com base nas decisões do projeto, não transcrições literais de todos os comandos originais.
