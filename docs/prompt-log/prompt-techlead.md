# Prompt Log — Tech Lead | Carrefort

Registro das atividades relacionadas à organização técnica, integração, versionamento e acompanhamento do desenvolvimento do projeto.

## Marco 1 — Estrutura e organização do projeto

**Objetivo:** organizar a base técnica para permitir o desenvolvimento colaborativo do Carrefort.

### Atividades realizadas

- Organização do repositório no GitHub.
- Acompanhamento da estrutura de pastas e arquivos do React com Vite.
- Organização da integração com o Supabase.
- Apoio na definição da estrutura das tabelas e relacionamentos do banco de dados.
- Acompanhamento da integração entre os módulos desenvolvidos.

## Marco 2 — Versionamento e integração

**Objetivo:** manter o código organizado e acompanhar a evolução das funcionalidades.

### Atividades realizadas

- Organização do versionamento utilizando Git e GitHub.
- Acompanhamento de commits e versões do projeto.
- Integração dos módulos de estoque, alertas, ofertas e movimentações.
- Acompanhamento de correções e ajustes técnicos.
- Verificação da compilação e funcionamento da aplicação durante as entregas.

## Marco 3 — Validação e entrega do MVP

**Objetivo:** acompanhar a estabilidade e preparar o projeto para apresentação.

### Atividades realizadas

- Acompanhamento dos testes das funcionalidades principais.
- Verificação da persistência dos dados no Supabase.
- Acompanhamento dos ajustes de interface e responsividade.
- Organização dos arquivos e documentação para entrega.
- Apoio na preparação do repositório e apresentação final.

### Entrega

- Projeto integrado e versionado no GitHub.
- Versões `v1.0.0` e `v1.1.0` registradas.
- MVP organizado para demonstração e entrega.
